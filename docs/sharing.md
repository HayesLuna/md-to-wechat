# 文章分享

分享只上传当前文章的快照，不上传草稿库、浏览器偏好或存储凭证。正文、排版设置和文中引用的本地图片放入一个 `.mojian` ZIP 文章包。公开 URL 图片保留原地址，因此仍依赖原站可访问。

## 使用

1. 点击顶部“分享”旁的设置图标，打开独立的存储设置，选择阿里云 OSS、腾讯云 COS 或 MinIO。
2. 填写 Bucket、Region、访问凭证；MinIO 还需填写 HTTPS 的 S3 API Endpoint。OSS Region 可使用 `cn-hangzhou` 或 `oss-cn-hangzhou`；COS Bucket 需包含 APPID。
3. 可选 Endpoint、存储目录和临时凭证收在“高级设置”中。临时凭证填写同一套临时 AccessKey 与 Token，无需填写凭证到期时间；长期凭证请使用仅限分享目录的专用账号。
4. 点击“测试连接”，验证一次临时文件上传、签名下载、删除。测试成功后保存配置。
5. 点击顶部“分享”，选择 1 小时、1 天或 7 天，生成分享链接，再复制给好友。已有链接只显示实际到期时间；点击“生成新链接”后再选择新的有效期。
6. 好友打开链接后先看到导入确认弹窗；点击“导入到本地”后才下载、校验并导入本地草稿，不需要配置存储。取消不下载文章或导入草稿。重复打开并确认后，会优先使用已经导入的副本，不覆盖修改；本地副本删除后可在链接有效期内重新导入。

分享是固定快照。本地继续编辑不会更新已发出的内容，再次生成会创建另一份快照。分享信息保存在发送方浏览器，弹窗仅显示当前文章最近生成的链接，可复制或取消分享，不展示草稿或历史分享列表。生成新链接不使先前发出的链接失效；取消当前链接后也不会重新显示旧链接。已导入的副本不会被远端删除影响。

## 凭证与私有桶

桶可以保持私有。发送方浏览器通过厂商 SDK 上传并生成仅用于 GET 的预签名地址。接收方链接不包含 AccessKey Secret/SecretKey，不包含上传或删除授权。签名地址按厂商协议可能包含公开的 AccessKey ID、签名和临时会话 Token；它们不是完整的发送方访问凭证，但整个链接属于持有即可读取的授权，请按文章的私密程度保管。

默认将凭证放在 `sessionStorage`，仅用于当前标签页会话；普通配置保存在 `localStorage`。主动勾选“在此浏览器记住凭证”后才将凭证保存到 `localStorage`。取消勾选并保存会移除先前持久化的凭证。“清除凭证”同时清除本标签页会话和持久化凭证，不删除文章或远端文件。浏览器本地存储不是保险箱，同源脚本可以读取；不提供虚假的“本地加密保险箱”承诺。

临时凭证不自动刷新，过期后需手动更新。链接设置的有效期最多 7 天，界面显示最晚到期时间。临时凭证先到期时，链接随之提前失效；工具收到存储服务返回的明确凭证过期错误后，会提示发送方更新凭证，接收方则提示联系发送方重新分享。凭证若提前撤销、权限变更或文件被删，链接也会提前失效。

## 桶配置

- 访问权限仅授予所配置目录，默认 `mojian/shares/`。需要对象读取、写入、删除，不需要列出桶或修改桶配置。
- 配置 CORS：允许工具实际来源（协议、域名、端口）执行 `GET`、`PUT`、`DELETE`、`HEAD`；允许所需请求头（可设置 `*`），暴露 `ETag`、`x-oss-request-id`、`x-cos-request-id` 等响应头。
- 前端和存储均使用 HTTPS。MinIO 填 API 地址，不是控制台地址。OSS 的可选 Endpoint 是官方地域 API Endpoint；COS 的可选 Endpoint 是可直连该桶的域名。第一版不提供 OSS CNAME 或 CDN 回源配置。
- 在分享目录配置生命周期规则，例如创建 8 天后删除。签名到期只阻止后续访问，不等于立刻删除文件。选择比分享期限短的清理时间会提前破坏链接。
- 使用版本控制的桶需要同时处理非当前版本清理；普通删除可能只产生删除标记，存储仍会计费。缓存层也可能延后文件删除的可见性。
- 若上传成功后客户端断网或关闭页面，可能留下没有本地分享记录的对象，依靠生命周期清理。

官方参考：[OSS 预签名下载](https://help.aliyun.com/zh/oss/user-guide/how-to-obtain-the-url-of-a-single-object-or-the-urls-of-multiple-objects)、[COS 预签名 URL](https://cloud.tencent.com/document/product/436/35651)、[AWS SDK S3 预签名接口](https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/migrate-s3.html)。

## 实现边界

- `articlePackage.ts`：协调本地图片读取和原子导入；按任务启动独立 Worker，完成、出错、超时或取消后终止，不在主线程降级执行重计算。
- `packageCodec.ts` 与 `articlePackage.worker.ts`：处理厂商无关的 v1 ZIP 格式、压缩、解压、校验和图片引用重写；Worker 只接收文章和图片，不接收存储凭证或加载厂商 SDK。
- `imageReferences.ts`：一次解析收集真实图片及原文地址位置；导入时复用这些位置替换 ID，支持 Markdown 转义、实体、引用式图片和原始换行格式，其余正文保持不变。
- `types.ts`：统一存储能力 `upload`、`downloadURL`、`remove`。
- `adapters.ts`：按需加载各厂商 SDK。COS 使用源码入口，单独覆盖 XML 依赖的修复版本，避免使用预打包的旧 XML 解析器。
- `service.ts`：创建快照、链接编码、下载校验、导入、连接测试与取消分享。
- `storage.ts`：通过一个 IndexedDB 事务写入图片、草稿、摘要和导入映射；并发导入同一分享不创建重复副本。
- 链接将 v1 描述（分享 ID、只读签名 URL、到期时间、文章包 SHA-256）放在 URL fragment 中，兼容 GitHub Pages 子路径，不需要服务端路由。
- 接收方加载工具后才请求存储，不加载发送方的存储配置或 SDK。下载不发送浏览器 Cookie 或 Referer，导入完成/退出后清除 fragment。
- 单篇正文最多 5 MB，最多 100 张本地图片，每张最多 10 MB，整个压缩包和解压总量最多 50 MB。先校验全部内容，再原子提交；失败不覆盖当前文章，也不留下半份导入。
- SHA-256 校验检查传输完整性，不代表作者身份认证。分享包不包含只读锁定状态、原草稿 ID 或其他草稿元数据。
- 切换存储只影响新分享。旧链接继续依赖旧存储地址、对象和签名，不自动迁移。取消旧分享需恢复对应存储配置和有效凭证。

## 验证范围

自动化测试使用实际 SDK 生成签名，并通过可控 HTTP 响应验证三种适配器的上传、下载、删除及两个独立浏览器会话之间的文章/图片导入。它不替代实际账号的权限、CORS、网络和计费验证。实际使用前，应在目标桶执行“测试连接”，再用另一台设备打开含本地图片的分享。

2026-10-31 本地验收：393 项全量 Playwright 回归通过；补充离线加载和存储不可用保护后，25 项分享/草稿/只读定向回归通过；lint、格式检查、生产构建、`git diff --check` 通过。桌面 1440×1000 和移动端 390×844 已检查布局。生产构建另外使用三个真实 SDK 与模拟存储端验证上传、签名、导入本地图片和取消分享，首屏不请求分享 SDK，无运行时错误；OSS SDK 使用长期凭证时发出的 STS 建议提示属于预期。

另使用本机已有的 `minio/minio:RELEASE.2025-09-07T16-13-09Z` 临时容器完成真实私有桶验收：连接测试、文章包上传、签名下载、独立接收方恢复本地图片、取消分享后返回 404，均通过。只在独立测试浏览器上下文信任了本次生成的自签名本机证书，未修改系统信任或应用 TLS 配置，临时容器已停止。真实 OSS、COS 账号及实际部署域名的权限、CORS、网络仍需接入后验证。

本轮 Worker 优化验收：91 项分享、性能、草稿、只读及工作流回归通过，lint、格式检查和生产构建通过。生产包使用真实 SDK 与模拟存储端分别完成 OSS、COS、MinIO 的上传、独立接收方恢复图片及取消分享，并确认打包和解包实际运行在 Worker。桌面及手机视口的生成、复制和重新生成流程通过，无应用运行时错误。Chromium 主线程 4 倍 CPU 降速、隔离测量下，48.19 MB 测试 PNG 图片包生成的最大帧间隔由 733 ms 降到 17 ms，160 万字符带图正文解包由 233 ms 降到 17 ms；这两项操作均未检出主线程长任务。以上不代表手机实机或线上目标桶验收。
